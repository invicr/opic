은행 묘사
EN: Well... / you can find banks / almost everywhere in the city.
KR: 음... / 당신은 은행들을 찾을 수 있습니다 / 도시 거의 모든 곳에서.
EN: Most banks / are clean and quiet.
KR: 대부분의 은행들은 / 깨끗하고 조용합니다.
EN: But honestly, / I haven't been to a bank / in a long time.
KR: 하지만 솔직히, / 나는 은행에 가본 적이 없습니다 / 오랫동안.
EN: These days, / I can do almost everything / with mobile banking.
KR: 요즘에는, / 나는 거의 모든 것을 할 수 있습니다 / 모바일 뱅킹으로.
EN: Also, / banks close too early, / so it's hard for me to go there.
KR: 또한, / 은행들은 너무 일찍 닫습니다, / 그래서 그것은 어렵습니다 내가 그곳에 가는 것이.
EN: Anyway, / there are banks everywhere, / but I don't go there very often.
KR: 어쨌든, / 은행들은 모든 곳에 있습니다, / 하지만 나는 그곳에 자주 가지 않습니다.
