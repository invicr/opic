여행 준비 단계 설명
EN: Well... / when I plan a trip, / I always compare / prices.
KR: 음... / 내가 여행을 계획할 때, / 나는 항상 비교합니다 / 가격을.
EN: First, / I decide / where I want to go.
KR: 먼저, / 나는 결정합니다 / 어디에 내가 가고 싶은지를.
EN: Then, / I check flights and hotels / on different websites / because I want to find / a better deal.
KR: 그런 다음, / 나는 항공편과 호텔을 확인합니다 / 다른 웹사이트들에서 / 왜냐하면 나는 찾고 싶기 때문입니다 / 더 좋은 조건을.
EN: I compare prices / before I make / a reservation.
KR: 나는 가격을 비교합니다 / 내가 하기 전에 / 예약을.
EN: Honestly, / it takes some time, / but I enjoy / finding a good deal.
KR: 솔직히, / 그것은 시간이 좀 걸립니다, / 하지만 나는 즐깁니다 / 좋은 조건을 찾는 것을.
EN: In the end, / I can save some money, / so it's totally worth it.
KR: 결국, / 나는 돈을 조금 아낄 수 있습니다, / 그래서 그것은 완전히 가치가 있습니다.
